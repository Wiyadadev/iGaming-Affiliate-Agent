# Affiliate Operations Workspace

Built a full-stack affiliate operations tool using Python, FastAPI, SQLAlchemy and vanilla JavaScript. The workspace connects partner offers, campaign analytics, human-reviewed content, and conversion tracking in one interface.

Key engineering work includes reliable startup without AI credentials, configurable OpenAI draft generation, approval state transitions, idempotent tracking-link preparation, input validation, access-token protection, and automated workflow tests.

The public interactive demo demonstrates the complete review workflow using fictional data and simulated conversions. The database-backed local workspace preserves existing project data and keeps optional AI and Telegram credentials on the server.

**Demo:** https://wiyadadev.github.io/iGaming-Affiliate-Agent/
